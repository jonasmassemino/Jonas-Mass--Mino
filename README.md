## Jonas Massé-Mino

Développeur dans la région de Québec (aussi écrit Jonas Masse-Mino).

Je construis des outils web avec l'aide d'agents d'IA, et j'expérimente ce que cette façon de travailler permet
vraiment : découpage du travail en petites étapes, tests à chaque étape, relecture humaine avant de livrer.

En 2023, avec trois camarades de classe, j'ai créé le mot **spectatriche**, choisi parmi 746 propositions par
l'Office québécois de la langue française pour nommer en français la pratique du « stream sniping ». Le terme
[spectatricherie](https://vitrinelinguistique.oqlf.gouv.qc.ca/fiche-gdt/fiche/26561650/spectatricherie) figure
depuis dans la Vitrine linguistique de l'OQLF
([communiqué](https://www.oqlf.gouv.qc.ca/office/communiques/2023/20230525_concours_creativite_lexicale.aspx)).

Je conçois aujourd'hui un outil de visibilité IA (GEO) qui vérifie si les entreprises québécoises sont
recommandées par ChatGPT, Perplexity et les autres assistants, analyse les sources qu'ils citent, et propose
trois actions concrètes par semaine.

**Techniques :** TypeScript, Next.js, PostgreSQL, développement assisté par IA
**Langues :** français, anglais
